# JLP Real Análises Clínicas

Site institucional atualizado e preparado para armazenamento no GitHub e publicação gratuita.

## Conteúdo incluído

- Página inicial informativa e responsiva.
- Página de exames com pesquisa, filtros e contato pelo WhatsApp.
- Seção destacada com os convênios divulgados pelo JLP.
- Informações sobre a importância dos exames e do acompanhamento da saúde.
- Foto do Dr. Marcial Luiz Patriarca.
- Foto da fachada e endereço do laboratório.
- Referências oficiais do Ministério da Saúde, OMS e INCA.
- Botões de contato direto pelo WhatsApp.
- Adaptação para computador, tablet e celular.

## Arquivos

- `index.html`: página inicial.
- `exames.html`: página de exames.
- `style.css`: visual e adaptação para celulares.
- `script.js`: pesquisa, filtros e menu móvel.
- `assets/`: fotos e ícone do site.

Não é necessário instalar React, Node.js ou banco de dados.

## Colocar no GitHub sem Visual Studio Code

1. Extraia o arquivo ZIP no computador.
2. Entre em [github.com](https://github.com/) e crie um repositório.
3. Para preservar melhor os códigos, selecione **Private**.
4. Abra o repositório e clique em **Add file** > **Upload files**.
5. Arraste todos os arquivos extraídos, incluindo a pasta `assets`.
6. Clique em **Commit changes**.

Importante: envie os arquivos extraídos. Não envie somente o ZIP.

## Publicação recomendada

Para manter o repositório privado e publicar gratuitamente, conecte-o ao Cloudflare Pages. O endereço poderá ficar semelhante a `jlp-real-analises.pages.dev`. Sempre mantenha `index.html` na raiz do repositório.

## Atualizações futuras

Altere ou substitua os arquivos no GitHub e confirme em **Commit changes**. Quando o repositório estiver conectado à hospedagem, a nova versão será publicada automaticamente no mesmo endereço.
